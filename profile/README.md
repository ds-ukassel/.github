The Internet is the largest distributed system ever built, and our mission is to empirically understand and optimize the Internet. Our research and teaching activities are concerned with the design principles of modern network and distributed systems, as well as their security aspects and valuation of user perception.

# Repositories
### 🍴️ Maintained Forks
- [ngx-semantic-ui](https://github.com/ds-ukassel/ngx-semantic-ui) - Semantic UI Angular Integrations (no jQuery) – Internal fork maintained for FIT
- [rancher-update-action](https://github.com/ds-ukassel/rancher-update-action) - A Github action to upgrade a service in Rancher 2.X.X
- [yaml-ls-check](https://github.com/ds-ukassel/yaml-ls-check) - Check YAML files against schemas using yaml-language-server

### 🌐️ Apps
- [coffee-counter](https://github.com/ds-ukassel/coffee-counter) - Coffee tracker for Distributed Systems Group
- [fit-public](https://github.com/ds-ukassel/fit-public) - Public Issue Tracker and Releases for FIT Newsletter

### 🛠️ Tools
- [cdns](https://github.com/ds-ukassel/cdns) - A list of CDN providers with different attributes for identifying them in different datasets with a collection of tools/libraries
- [backup-mongodb-s3](https://github.com/ds-ukassel/backup-mongodb-s3) - Script/Docker tool to backup MongoDB to S3/MinIO using mongodump
- [backup-postgres-s3](https://github.com/ds-ukassel/backup-postgres-s3) - Backup PostgreSQL to MinIO/S3
- [backup-clickhouse-s3](https://github.com/ds-ukassel/backup-clickhouse-s3) - Node/Docker tool to backup Clickhouse to S3/MinIO using builtin "BACKUP TABLE". Supports incremental backups.
- [backup-clickhouse-native-s3](https://github.com/ds-ukassel/backup-clickhouse-native-s3) -  Script for backing up clickhouse to s3 compatible storage like minio using native formats
- [trace-that-route-server](https://github.com/ds-ukassel/trace-that-route-server) - Simple FastAPI HTTP server for trace-that-route (exposes traceroutes to a POST endpoint)
